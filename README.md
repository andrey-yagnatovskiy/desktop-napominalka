# Напоминалка для Windows 11

Приложение на Python с интерфейсом tkinter и хранилищем SQLite3. Сторонние пакеты не нужны.

## Требования и запуск

Нужен Python 3.11 или новее с компонентом Tcl/Tk (tkinter). В стандартном установщике Python для Windows этот компонент обычно включён. Если Python отсутствует, его нужно установить отдельно; приложение ничего не устанавливает автоматически.

Откройте PowerShell в папке приложения и выполните:

```powershell
py -3 app.py
```

Если запуск доступен через команду `python`, можно использовать `python app.py`.

## Использование

1. Нажмите «Добавить», введите заголовок, необязательное описание и будущую дату в формате `ДД.ММ.ГГГГ ЧЧ:ММ`.
2. Выберите запись в списке, чтобы прочитать её описание или нажать «Готово», «Отменено», «Удалить». Удаление требует подтверждения.
3. Используйте список «Статус» для фильтрации. Доступны «Все статусы», «Ожидает», «Готово», «Просрочено», «Отменено».
4. Сверните главное окно: проверка времени продолжит работать.

Сроки задаются в местном времени Windows с точностью до минуты. Проверка выполняется примерно раз в секунду через цикл событий tkinter, без фоновых потоков.

При наступлении срока поверх окон появляется отдельное уведомление. Через минуту после срока запись со статусом «Ожидает» становится «Просрочено». Кнопки «Готово» и «Отменено» меняют статус; кнопка «Закрыть» не меняет статус.

Если наступило несколько сроков, уведомления показываются последовательно, начиная с самого раннего. Во время заполнения формы добавления popup ожидает закрытия формы; проверка сроков при этом продолжается. Уведомление о каждой записи показывается один раз за запуск приложения. После перезапуска все оставшиеся просроченные записи снова попадают в очередь уведомлений.

**После закрытия приложения уведомления не работают.** Автозапуск и фоновая служба не предусмотрены. Во время сна или выключения компьютера уведомления не появляются: пропущенные сроки обрабатываются после пробуждения при работающем приложении либо при следующем запуске. Статусы «Готово» и «Отменено» автоматически не меняются.

## Файлы и данные

- `app.py` — интерфейс, проверка сроков и popup-уведомления.
- `database.py` — создание таблицы, запросы SQLite и изменение статусов.
- `reminders.db` — создаётся автоматически при первом запуске рядом с `database.py`, независимо от текущей папки PowerShell.

Для новых записей сохраняется время создания. При обновлении существующей базы соответствующее поле добавляется автоматически; для старых записей оно остаётся пустым, поскольку прежнее время создания неизвестно.

Папка приложения должна быть доступна для записи. Для резервного копирования закройте приложение и скопируйте `reminders.db`. Данные не передаются приложением в сеть; файл SQLite хранится без шифрования. Если папка находится в OneDrive, её файлы могут синхронизироваться средствами Windows и OneDrive.

Рекомендуется запускать один экземпляр приложения: каждый экземпляр имеет свою очередь уведомлений. Даты хранятся как местное время без часового пояса; при смене часового пояса или часов Windows сроки интерпретируются по новым местным часам.

## Ручная проверка

1. Запустите приложение в папке без `reminders.db`: база и таблица должны создаться автоматически.
2. Добавьте запись со сроком через 1–2 минуты. Сверните окно и дождитесь popup поверх обычного окна другого приложения.
3. Нажмите «Готово»: запись должна появиться в фильтре «Готово» и сохраниться после перезапуска.
4. Повторите для «Отменено». Если закрыть popup без смены статуса, запись станет «Просрочено» через минуту после срока.
5. Создайте две записи с одинаковым сроком: после закрытия первого popup должно появиться второе уведомление.
6. Закройте приложение до наступления срока и запустите после него: запись должна стать просроченной и вызвать уведомление.
7. Проверьте удаление с подтверждением и отказом от удаления, пустой заголовок, неверную дату, дату в прошлом и сохранность многострочного описания.

Проверка синтаксиса без запуска интерфейса и создания файлов кэша:

```powershell
py -3 -c "import ast, pathlib; [ast.parse(pathlib.Path(p).read_text(encoding='utf-8'), filename=p) for p in ('database.py', 'app.py')]; print('Синтаксис: OK')"
```
